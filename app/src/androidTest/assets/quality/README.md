# Multi-audio preference fixture

`multi-audio.mkv` is generated by `release-stable.yml` using FFmpeg's blue color and two sine generators. Its first AAC stream is tagged `eng` and default; the second is tagged `jpn`. It contains no private media and is packaged only in the instrumentation APK. `PlayerAudioPreferenceTest` verifies real language selection, missing-language fallback and manual override.

`framing.mp4` is generated by `scripts/generate-framing-fixture.py`: 320×180 with encoded top/bottom black bars, a central white circle, and red/green side markers. The actual-window test verifies a round enlarged circle and removed side markers in crop mode, a vertically deformed circle in stretch mode, and original proportions/bars in fit mode. It never enters the application APK.
