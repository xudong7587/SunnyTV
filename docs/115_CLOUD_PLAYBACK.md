## 使用方式

沿用 Emby → MediaIndex STRM 稳定入口。在播放器的清晰度面板点击“查询 / 刷新 115 云端清晰度”，由 MediaIndex 核对当前 asset token 对应的 115 文件，再查询实际可用档位。打开菜单本身不会请求 115 视频接口；显式查询可能触发 115 自己的云端转码准备。

菜单区分原片、115 云端和 NAS 转码。云端标签来自主清单的尺寸及声明码率，不代表实测编码质量或官方 App 的同名档位。默认仍是原片。115 Cookie 只留在 MediaIndex 的现有配置中，不进入 SunnyTV。

选定云端档位后重新解析短期流。默认优先直连：MediaIndex 只转发清单及小型 AES 密钥，视频、音频分片和初始化段由 SunnyTV 直接从 HTTPS 115 CDN 下载，不占 NAS 的视频吞吐。可手动选择 NAS 代理后重选档位；不会在失败时自动切为代理。两种方式都不运行 NAS FFmpeg。

完整 VOD 使用原生时间轴和 seek；不调用 NAS 暂停、续租或心跳接口。云端切换采用解析完成时的当前位置及播放/暂停状态，避免查询期间继续播放造成回退；解析失败保留原播放器。NAS→NAS 仍先释放旧名额，以兼容单并发 worker；失败明确提示并恢复原片。

## 已知限制和待验收

1. 本机只读账号探测返回 115 登录过期 `990001`。用户选择“先完成代码与模拟测试，暂不登录”，因此停止真实账号验证。尚未验证真实响应结构、档位覆盖、Cookie 类型、会员权限、HTTPS CDN 可用性与官方 App 画质一致性。
2. 只支持已映射到 MediaIndex 115 文件的稳定入口；任意 Emby 文件或 CD2 地址不会凭文件名猜测 115 文件。
3. 只接受完整 VOD、多档主清单及支持的 URI 类型，支持 AES-128 identity；不支持 DRM、动态地址、直播或滚动清单。没有可用档位时显示原因。
4. 签名流过期后需重新选择档位；当前不自动刷新。没有真实长时间播放、音轨/外部字幕或 TV 实机验收。
5. 网关会话保存在单进程内存；多 worker 部署需粘性路由或后续共享会话实现。重启会失效。会话最多 32 个，闲置 2 小时、绝对寿命 8 小时；客户端退出主动清理。
6. 配套网关和客户端必须一起更新后才能使用新功能；旧网关返回清晰提示，原片与既有 NAS 能力保留。MediaIndex 的 NAS 服务按项目约定由用户从 GitHub 发行版手动升级，本轮不操作其运行目录。
7. 直连会将必要的短期 CDN 签名地址交给播放器，但不交出 Cookie；不写诊断日志。网关撤销会话无法立即撤销已下发的 CDN 地址，它们受 115 自身有效期限制。真实跨出口 IP、Cookie 依赖和网络兼容性待验证。
