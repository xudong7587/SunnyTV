# SunnyTV 0.3.9 灯带移植与验证

## 基线与改动边界

本版从输出目录 0.3.8 对应提交 `f1355994e8dbba51baa2dafd835e41109e3a74b0` 开始，仅移入灯带功能。
基线 APK 为 `SunnyTV-v0.3.8.apk`，SHA256 `b8e5b6bd026421b0b185aac79b21353727b193430fd8ff13afd7a25d6ce4d917`。
沿用 0.3.8 的原生 TV PlayerView/SurfaceView、OSD、缩放、字幕、网络、媒体来源及界面。
既有文件仅接入 SunnyApp 生命周期、PlayerActivity 取色启停、设置灯带分类、可选蓝牙权限和递增版本号。
灯带代码来自此前验证的 `7801692`，未整合旧分支的其它文件。

## 同步与色彩

- 仅读取 SunnyTV 自己的视频 Surface，不申请录屏、不截取 HDMI 或其他应用。
- 保留 ZOOM 可见区域到解码缓冲区的坐标换算和整条黑边检测。
- 在 160×90 的复用位图上，取有效画面上/下高度 5%、左/右宽度 5% 的边缘条带，整像素向下取整、至少 1 像素。
- 每边一色；中心区域不参与四边平均。四角有相邻条带重叠，比例较小。
- 默认开启色彩增强：饱和像素权重 `1+3*s*s`，平均后饱和度 ×1.60、有色亮度 ×1.20 并限幅，保留色相。纯黑、灰、白保持中性。
- 设置内“色彩增强”可切换自然平均；不覆盖用户固定色及总亮度。
- 默认 10 次/秒，可选 5/10/15。PixelCopy 提交和颜色计算在专用工作线程；一帧在途、蓝牙待发送目标只留最新值。
- SP658E 的七个静态色段限制仍存在；本版并非逐灯珠全画面传输。

## 生命周期

应用级 Activity 开始/停止按身份计数；主界面与播放器交接不会作为退出。
播放且同步开启时发送四边颜色；停止/暂停或播放器退出而 SunnyTV 仍显示时恢复设置中的固定色。
所有 SunnyTV Activity 均停止（返回桌面、Home、切换其它应用）后等待 350 ms 排除页面交接，使用已经实测的静态全黑命令熄灭所有 RGB 灯珠，再延迟 2.2 秒关闭 GATT。
全黑不是断电或未经验证的设备电源命令；重新进入应用仍能恢复已保存固定色并继续同步。
后台拒绝迟到的取色/定位/色板预览，退出后色板销毁也不能重新点亮。
正常生命周期退出适用；断电、进程强杀或已经丢失蓝牙时无法保证最后一条命令送达。

## 配置与协议

保留 ambilight SharedPreferences，包括连接地址、开启状态、固定色、亮度、帧率和校准；新增 vivid 默认 true。
默认仍使用用户校准的 96 个控制单元，零基角标左上49、右上18、右下3、左下65，方向 -1，四边长度31/15/34/16；下边两端已按用户最后要求恢复。
支持遥控器连接、末端/四角向导、边界±1、四边测试、固定色色板及预览。
控制目标严格限制 SP658E / V4023.21 / SPI RGB。包和通知解码沿用已抓取、实测的命令，不引入动态或音频模式。
