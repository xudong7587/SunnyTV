## 首页沉浸轮播

- 总首页上部约占实际窗口高度 70%，适配安全区/字体，不硬编码 4K 坐标；下面保留原生库图入口、继续观看、NextUp、最新入库。
- 当前影片为大背景、标题/媒体 Logo、元数据、简介、播放/详情按钮，结合渐变与留白；其他候选为可辨认的竖条预览，左右循环。
- 设置可选继续观看或随机推荐；随机推荐可选全部/部分媒体库，选择标识含 sourceId 和库 ID。候选集有界按需加载，不全库扫描、不因焦点移动解析播放直链。
- 空候选、无续播、未选库和服务失败应有合理空态，不能静默扩大用户限定的媒体库范围。
- 焦点进入任何轮播控件（播放、详情、竖条）立即停止自动切换；按钮对应影片保持稳定；左右可手动循环。离开后重新开始完整间隔，不抢焦点。
- 离开首页、后台、滚出可见区、遮挡弹窗、准备播放或用户暂停时停止计时。减少动画/辅助功能提供静态或暂停策略，避免叠加计时器。
- 快速按键优先响应焦点，旧图片请求不能覆盖新选择，返回恢复合理焦点和选择；优先时间驱动的透明度/位移/轻量缩放，不逐帧重排整个列表。

## 播放器媒体 Logo

全屏播放不显示全局导航。左上角用当前媒体 Emby Logo，剧集可用服务器提供的系列 Logo；无图、认证失效或加载失败回退片名，不回退 SunnyTV 品牌。保持透明度、比例和来源鉴权；随 OSD 显示/隐藏，不常驻遮挡影片。

## 4K / 144 Hz 目标与诊断

4K / 144 Hz 是用户报告的面板规格，不能等同应用渲染尺寸或实测帧率。
先采集 Android 版本、ABI、支持/当前显示模式、窗口/UI 渲染尺寸、刷新率、可用内存、实际帧时间与视频输出，之后在可用能力范围优化。
不改系统 wm size/wm density，不硬写 144 冒充支持，不把影片源帧率、UI 刷新率和视频输出混淆，不强制插帧。
按显示尺寸请求/解码 Emby 图片，控制缓存、并发、预取和低内存回收，不让小卡片持有完整 4K 背景。
动画使用系统帧时钟；60/120/144 Hz 的理论帧预算为 16.67/8.33/6.94 ms，属于计算值。
在可 profile 且接近发布的构建上测连续遥控导航、轮播暂停、主题切换、详情返回、播放退出及 30 分钟内存/卡顿趋势。
