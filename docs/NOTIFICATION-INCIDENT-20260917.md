## SunnyTV 本轮处理

1. 整剧、整季和文件夹不提供“标记已看”；适配层也拒绝批量写，防止只隐藏按钮却保留可调用路径。
2. 单片/单集已看操作先显示明确确认；确认键长按重复事件被拦截。
3. 收藏和已看使用服务端返回状态更新详情与已加载列表，已收藏/已看明确显示选中状态，失败弹出提示。
4. 新增 MockWebServer 测试验证：浏览首页/随机推荐、进入剧集和季集只用 GET；批量标记被拒绝且没有任何 HTTP 请求；收藏/已看写入与撤销解析真实响应。
5. 设备交互测试改用不恢复真实账号的中立测试宿主，不使用用户的媒体条目做状态写入测试。

## 仍需区分

- 本地代码路径检查没有发现进入详情就直接调用播放或已看接口的代码，但旧版确实产生了以上状态写入。快速按键、触摸和页面切换的精确触发仍需受控复测；本轮手机测试按用户要求暂缓。
