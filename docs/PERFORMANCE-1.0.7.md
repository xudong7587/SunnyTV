# 1.0.7 /80 自适应取色密度（开发中，未发行）

用户要求仅在性能不足的视频中降级，能算得过来时保留精度。当前实现每段新播放先用32×18进行一次低成本探测，<=25ms时恢复160×90；详细读回>60ms则切回小网格。轻量模式至少等待30秒且连续6次<=16ms后才重新探测详细模式，避免逐帧反复切换。所有模式仍保留10%时间预算与单请求在途约束。

详细模式>=250ms时不重复该慢路径，改用轻量模式；如果轻量读回也>=250ms则暂停当前播放同步并保持灯色。重新开关画面同步或新播放重置保护。快关快开产生新的采样代数，旧完成回调不能重新施加前一代的质量决策或退避时间。两套网格复用各自位图与数组，不按帧分配。

这次只改变采样密度，输出仍为既有四边分区；不是逐灯珠或同边多位置输出。已向用户询问是否还需要更细的颜色分区，尚未收到选择；不能把这两种精度混为一谈或宣称已提供更细灯段。
