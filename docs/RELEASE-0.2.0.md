# SunnyTV 0.2.0

本次从已发布的 dev36.4 增量整合绿联影视中心连接，保留其音频解码、115清晰度、字幕和原生更新功能。安装ID和已有签名不变，versionCode由51递增为52。以后使用纯数字版本号，不再追加dev后缀。

- 设置 → 媒体来源新增“＋绿联影视中心”，首次连接也可选择；提示先在“影视中心 → 设置 → 服务管理 → 媒体服务器”开启服务并设置专用账号，提供官方说明。
- 自动补齐HTTPS媒体服务器地址的`/emby/`；适配按库最新内容、合集、季/选集、人物、片头片尾和直链/NAS取流回退。绿联不支持的全库搜索、排序、字幕搜索下载及管理操作不显示或不发送。
- 首页从任意顶部按钮按下，优先进入左侧第一个“继续播放”。没有续播内容或已隐藏时仍进入方块海报；海报左右轮换、从媒体区返回banner等既有导航保持。
