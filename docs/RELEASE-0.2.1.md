# SunnyTV 0.2.1

版本0.2.1，versionCode 53，沿用0.2.0的安装ID和签名。本次按反馈完善媒体来源设置与绿联本地排序，保留首页续播入口及既有播放功能。

- 添加按钮常显“添加 Emby 服务”“添加绿联影视服务”；紧凑布局纵向排列。清除按钮使用垃圾桶图标并常显“清除本地服务配置”，仍需原有确认才执行。

- 绿联提供名称升降序、评分、年份、时长、播放日期、比特率、大小及随机排序。名称升序沿用服务端分页；其它排序先取齐当前目录再由SunnyTV处理，不将单页排序伪装为完整排序。缺失数据排末尾，整个目录均缺少该字段时明确提示。
- 本地完整目录限10000项、累计8Mi字符及90秒；校验总数、重复ID、分页完整性和取消。只读取列表，不写回影视中心，不请求每个影片详情补齐缺失字段。

## MediaIndex 115云端清晰度

已有链路可复用：如果绿联PlaybackInfo仍保留MediaIndex原始`/api/play/{assetToken}`入口，播放器会从保留的sourceMediaUrl识别，查询已有`/api/cloud-video/discover`并使用现有会话。无需将绿联账号或token发给MediaIndex，标准MediaIndex来源保持。

此前真实绿联样本返回的是最终115 CDN直链，Path与DirectStreamUrl相同，已经缺少原始MediaIndex入口/授权。因此当前样本不能据CDN地址自动取得云端档位；需要后续可核验的原始入口映射或双方接口支持。没有读取NAS的STRM文件、提取凭据、修改MediaIndex或猜测授权。本次新增HTTP测试验证可复用路径及凭据隔离，并验证CDN/NAS流不会被误当作MediaIndex入口；这不代表当前真实绿联样本的云端清晰度已联调完成。
