# SunnyTV 0.2.4

软件音频库增加 AAC 解码支持。沿用播放器已有的软件音频优先策略处理 AAC，视频继续使用设备视频解码器，保留 AC3、EAC3、DTS 和 TrueHD 支持。

修复目标为部分 115 云端多声道 AAC 在 Android 系统解码器报错、导致整条视频出现 4003 的兼容问题。实测问题影片的云端 1080P 与 4K 都使用 44.1kHz、8 声道默认 AAC；设备系统 AAC 报错，NAS 既有软件解码能处理两路音频。该修复不恢复 NAS 转码或缓存服务，也不更改 MediaIndex、网盘凭据或原片路由。

修复 ADTS 声道配置为 0 时的不完整初始化数据：由帧内 PCE 提供真实声道布局，保留完整配置与标准布局不变。

新增 Android 原生解码回归：44.1kHz 双声道、5.1 与 7.1 AAC，从 ADTS 提取裸样本和音频配置，验证实际输出非静音 PCM。与已有 AC3／DTS／下混测试一起运行。新增声道配置为 0 的 5.1／7.1 PCE 样本。用户已带走手机，本版真实影片两档播放需更新后验收，不以模拟器测试替代手机或电视验收。

处理自定义 AAC 布局的中途起播：云端续播先读取开头建立布局，再回到原进度，保留暂停状态与后续拖动；不把预读位置保存为用户进度。新增真实 HLS／AAC PCE 的暂停续播、拖动和进度推进回归。此前 0.2.3 仅为未公开候选包，正式版使用 0.2.4／56，以便候选包用户正常收到更新。
