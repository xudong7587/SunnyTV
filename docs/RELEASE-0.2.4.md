# SunnyTV 0.2.4

修复部分 115 云端 1080P／4K 多声道 AAC 无法播放的问题。软件音频库加入 AAC；视频仍使用设备视频解码器，保留 AC3、EAC3、DTS、TrueHD 和原片播放。

问题影片的云端两档均为 AAC-LC 44.1kHz、默认8声道，ADTS声道配置为0，真实布局在帧内PCE中。Android系统AAC报4003；仅加入软件AAC的0.2.3候选仍因不完整初始化数据报4001。本版在HLS解析时提取完整布局，赶在播放器丢弃起播填充帧之前保留音频配置，供后续拖动或重建解码器使用。

仅在中途起播且缺少这类AAC布局时读取开头的布局信息，再回到用户进度；保留暂停及字幕选择，不把预读位置保存为用户进度。普通云端流按原进度直接起播。源链接、凭据隔离、重试边界及字幕解析方式保持不变；未修改MediaIndex或恢复NAS转码容器。

新增双声道、5.1、7.1、帧内PCE、无PCE中间帧冷解码、畸形配置和真实合成HLS的带字幕暂停续播／拖动／播放推进回归。正式发行要求源码构建、144项Gradle单测、33项Android定向回归及原签名检查通过。

用户已带走手机，实际《功夫梦》的云端1080P／4K和实体电视需安装后验收，不以模拟器测试替代实机。0.2.3仅为未公开候选；本版0.2.4／56可升级该候选包。
