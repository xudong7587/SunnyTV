# SunnyTV 0.2.5

- 播放器右上角新增实时信息开关，左上角以界面字体、小字号半透明底显示分辨率、帧率、格式、码率、下载速度、缓冲与解码器。每秒更新，控制栏收起后仍可见，偏好会保存。
- 视频/流标称码率与实时下载速度分别显示；未知数据使用破折号，不把网络估算冒充视频参数。
- 「实验升级」更名「软件升级」。GitHub 官方渠道在前，WebDAV 默认关闭，开启后显示账号、目录和自动更新；关闭保留配置并停止下载。
- WebDAV 按 GitHub latest 的 APK 文件名直接下载，不读取 WebDAV JSON；验证 APK 包名、版本、签名后拉起系统安装确认。GitHub 渠道保留官方 SHA-256 检查。
- 关于页 MediaIndex 改为文字「前往 GitHub 查看详情」。
- 修复云端外挂长字幕在暂停、拖动后偶发消失：使用字幕实际结束时间，避免被误判为已结束。
- 保留 0.2.4 的 AAC PCE 音频修复；用户已反馈《功夫梦》云端 1080P 和 4K 均可播放。

安装 ID、既有证书与四 ABI 音频解码能力保持不变。WebDAV 发布兼容旧版 JSON 入口，但 0.2.5 客户端不再读取它。
本轮新增界面仍需用户在手机与电视上验收；模拟器验证不能代表所有设备。
