# SunnyTV 0.2.7

- 申请 Android 大堆内存，播放缓冲预算提高到实际获准堆内存的 1/2，上限 512 MiB，同时限制在总内存的 1/8 和当前可用内存的 1/4 以内；系统低内存时进一步收紧。16 GB 物理内存不代表应用可以直接分配 16 GB，实际预算显示在播放信息中。
- 云端播放开始后遇到网络连接中断、等待响应 EOF、超时及临时 HTTP 服务错误时，原地重试失败请求，最多 4 次，保留播放位置与已缓冲媒体。证书、权限、格式及永久错误不无限重试。网络 EOF 提示不再误指向本地文件损坏。
- GitHub 更新直接在软件升级页显示两个按钮：当前版本及自动检查结果、下载并更新。下载显示百分比（服务器未提供大小时显示下载中），校验签名后自动打开系统安装器；授予安装权限返回后继续安装确认。

WebDAV 更新入口及后台自动检查暂时隐藏/停用，代码和已保存配置保留。

保留现有包名与签名，安装确认由 Android 系统控制。物理设备的内存授予、115 网络质量和长时间播放体验仍需实际验收。
