版本 0.3.1 / versionCode 63。用户要求完成后仅将 APK 放到 `Z:/V3 Download/tv apk`，不提交、推送或发布 GitHub。本版未再覆盖安装手机；0.3.0 历史包保留。

## 本轮修改

- 配色改为 7 个单色预设：晴蓝、青瓷、鸢紫、莓红、砖窑、琥珀、靛蓝。移除多色以及松绿、芥末、石墨入口，旧设置按色系迁移到保留预设。
- 新增自定义颜色：可拖动的色相/饱和度色盘、亮度条、6位 HEX；支持遥控器确定进入调整、方向键调节、再次确定退出，应用才保存，取消不写设置。主色保留，阅读与装饰层次通过 sRGB 亮度约束和同色明暗算法生成；语义状态色仍独立。
- 顶部四个导航按钮不再固定 50dp 胶囊；根据外框实际圆角（包含高度上限）减去 4dp 内距，保持内外同心。焦点与导航逻辑保持。
- 16 种原生材质及两列预览卡片，卡片内含样块、名称、说明和可用条件；样块使用同一原生绘制器。双色渐层按单色要求改名为“深浅渐层”。材质覆盖结构面板、操作按钮和输入框，保留内容与尺寸。
- “iOS 玻璃”改名为“液态玻璃”，不复制 Streama 反编译源码，不新增第三方材质库。

## 液态玻璃的实现与适用范围

真实背景效果用于顶部悬浮导航和材质样块。共享 Compose GraphicsLayer 记录页面显示列表，消费者不进入采样源，避免递归；只对玻璃覆盖区域加采样余量，执行原创 AGSL：圆角矩形 SDF、沿边缘法线位移折射、轻微透镜放大、9点柔化、方向高光和内沿暗部。文字/图标在效果之后绘制，不被模糊。雾面玻璃加大柔化，极光玻璃添加同色柔光。

普通内容面板和播放器控件采用对应的静态原生表面，不逐项抓取/模糊海报或视频。纸、亚麻、金属、石纹为缓存路径；色场和釉光为缓存渐变，柔软浮雕按下反转明暗层次。没有常驻计时器、传感器、截图读回或新增图片请求。高光不会自动持续流动。

玻璃需用户打开“允许高开销主题”、非低负载运行、Android 13+ 和硬件加速；霓虹需开关授权且非低负载。渲染端再次核验条件，关闭/低负载/不支持时回退清晰默认，保留所选偏好以便恢复。禁用玻璃时不创建背景特效层。低负载同时抑制材质阴影。
