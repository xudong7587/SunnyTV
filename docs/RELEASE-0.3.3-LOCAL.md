## 三个问题

1. 播放器右上角：实时信息原先关闭焦点标签，音频输出标签向上伸出屏幕。现在统一在按钮下方展开，按按钮实际高度留间距；保留原焦点目标和点击区域。
2. 跳过片尾：原先只seek到片尾边界，没有切集动作，且服务端时长不一定等于解码时长。存在下一集时直接调用相邻剧集切换并在启动协程前上锁；片头、无下一集仍执行原有跳过逻辑。未另行改变自然播完的自动播放政策。
3. 返回：统一页面内容与顶部导航的返回入口，不再吞掉首页返回。先正常逐层返回；到首页或1.8秒内连续三次返回后提示“再按一次返回退出软件”，2秒内再次按下则结束主Activity。其它按键取消退出待确认，长按重复事件不累计为多次确认；播放器仍先收起面板/控制条再退出播放。
