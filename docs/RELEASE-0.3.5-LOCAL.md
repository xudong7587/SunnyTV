## 玻璃与焦点

- 移除玻璃材质强制深色及强制白色主题强调色的覆盖。外观遵循用户深浅色设置与Monet；液态玻璃按钮深色用白字、浅色用黑字。
- 液态玻璃按钮取消硬焦点圈与聚焦缩放，以表面覆盖不透明度从28%到56%表示聚焦/选择；内部扁平按钮使用黑白选中覆盖。海报、媒体封面、媒体库图片和人物头像保留原主题色焦点。
- 页面独立按钮接入真实背景显示列表，复用相同折射、高光和轻模糊。每页登记背景图层，采样排除消费者按钮、文字和海报，避免递归；没有图片背景时使用页面背景。顶部容器内按钮继续扁平，弹层使用屏幕坐标计算局部采样。
- 修复滚动图层里的不透明黑块/厚黑边：旧高光shader即使没有高光也返回alpha=1，再经Plus混合写入透明离屏层。现在按高光覆盖率输出预乘alpha，并采用SrcOver。非滚动与离屏滚动图层对照中RGB最大差从118降至不超过3。
- Shader/RenderEffect按形状、尺寸及主题缓存；聚焦动画只改变覆盖色透明度，不重建shader。不做CPU截图，不引入定时刷新或新依赖。
