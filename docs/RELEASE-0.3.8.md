# SunnyTV 0.3.8

修复部分剧集打开详情时退出的问题，用户已确认本地测试包不再闪退。版本号为 0.3.8，versionCode 为 70。

- 详情页对重复演员、季、版本和推荐条目做容错，避免重复列表键导致退出。
- TV 视频改用 Activity 原生 PlayerView / SurfaceView；“适应 / 裁切 / 拉伸”显示当前模式，Activity 重建后保留选择。
- 外观增加独立配色、圆角和材质设置，支持莫奈配色、自定义颜色及按设备能力回退。玻璃遵循深浅色设置；液态中央更透明，极光使用内部淡彩，雾面使用斜切棱边。
- 修订返回首页后的退出操作、片尾下一集和清晰度/字幕面板的使用细节。
- 保留绿联私有 IPv4 HTTPS 证书连续性修复，证书只用于对应来源的主机和端口；首次检查不发送账号凭据，公网站点继续系统 TLS 校验。

本地已完成 debug/release 编译、177 项 Gradle 单测、172 项核心契约和签名/包内容校验。0.3.8 的 API34 定向回归最终 9 项通过，API30 播放器定向 5 项通过；更早的外观及网络验证见本地版本记录。正式 Linux 构建、原生音频及 Android 门禁由本次发布 Actions 执行并保留报告。用户已确认详情闪退解决，TV 比例修订仍待实体电视反馈；历史 TV 演员上下导航空闲超时继续记录在 KNOWN-ISSUES.md。

本次分发保留用户已测试 APK 的原始字节。发布流程重新构建并核对应用代码、资源、包身份及既有签名，另验证未修改的原生解码器来源。APK 为非 debuggable release，安装 ID 和签名身份延续现有版本。未包含私有字体、账号或签名密钥。

0.3.8 的增量测试包与全量重建包有一项已审查的 `classes2.dex` 差异，涉及 Compose 生成的稳定性/重组分支；Linux 与 Windows 全量重建的全部 DEX 字节一致。发布校验只认可本包 SHA256 和这组固定 DEX 哈希，其余 289 项应用 DEX、Manifest、资源与规范化许可证内容一致，不宣称此包可逐字节复现。差异及类哈希见 [审查记录](https://github.com/xudong7587/SunnyTV/blob/main/docs/release-evidence/0.3.8-dex-variance.json)。既有 debug Android 门禁保留，原始签名候选另执行原生音频、真实播放、字幕、详情及网络回归。
