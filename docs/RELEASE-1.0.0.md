# SunnyTV 1.0.0

本版整合液态玻璃界面、播放器修复和 0.3.9 灯带版功能，版本号 1.0.0，versionCode 73。沿用现有签名和安装 ID，可从同签名版本覆盖升级。

- 液态玻璃、极光与雾面外观支持深浅色及遥控器焦点；详情页增加重复数据容错。
- 播放器使用原生视频层，保留比例切换与恢复、字幕和云端清晰度功能。
- 加入 SP658E（V4023.21 / SPI RGB）灯带控制：视频四边取色、色彩增强、固定色、亮度、帧率、四角校准和退出熄灯。灯带默认关闭；保留 0.3.9 的默认校准数据和已保存设置。
- 液态玻璃源码仍作为 SunnyTV 的一部分公开，入口见 README 和 docs/LIQUID-GLASS.md；项目继续采用 GPL-3.0，第三方授权与署名保留。

关于页重写：SunnyTV 使用与导航栏一致的太阳标志，新增标语「精致入眼，流畅入戏。」；两个项目标题旁均可直接打开 GitHub，MediaIndex 使用原项目图标，并补充媒体整理与云端播放介绍。

既有灯带整合包已通过本地 192 项单测、172 项核心契约和 API30 定向回归。本次关于页修订的 release 编译、192 项单测、debug/release lint（各0错误/44警告）通过；API30 对实际签名 release 包执行关于页深浅色及宽窄布局/链接检查和灯带设置、四边取色，共4项通过。正式 APK 由 GitHub Actions 使用现有仓库密钥从本标签源码构建。最终版本、SHA256、签名及构建信息见发行附件。

实体 TV 灯带效果与延迟仍待用户测试；历史演员导航超时问题见项目状态文档。
