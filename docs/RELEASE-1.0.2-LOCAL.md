# SunnyTV 1.0.2 / 75 · 玻璃弹窗与每部媒体的默认音频

## 改动

- ChoiceDialog共用一层玻璃外壳，复用顶部导航的完整页面记录，包含海报墙与页面内容；不会透过海报直接取底层背景图。取消原生弹窗的页面压暗。内部选项不再分别折射，使用柔和磨砂底、独立焦点和矢量勾选。标题与说明分开，取消按钮常显文字。
- 排序选项等宽、等高，名称和勾选固定对齐；当前方向放到统一说明中，竖屏两列、宽屏三列，受限高度可滚动。
- 电影、剧集/季的详情页增加“默认音频”：跟随媒体默认、国语、粤语、英语、日语、韩语、法语、德语、西班牙语。按带来源前缀的媒体key保存到本机；媒体库工具栏不增加此按钮，不写服务端设置。
- 播放优先采用详情页显式选轨，其次此媒体的语言偏好；每部影片从自身MediaStreams重新解析索引。单集可覆盖剧集/季的偏好，没有单集设置时继承所属剧集。没有匹配时保持媒体默认；缺少服务端轨道元数据时在Media3实际轨道到达后匹配语言。国语和粤语区分，兼容常用两字母/三字母语言码。
- 连续播放下一集重新匹配该集轨道，不复用上一集流索引或单集自己的语言覆盖。已有字幕偏好修正当前媒体库横幅直接播放时尚未进入返回栈的读取边界。
