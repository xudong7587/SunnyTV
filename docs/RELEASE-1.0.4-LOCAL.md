## 改动

- Android 11–12L（API30–32）新增真实页面背景玻璃兼容路径：共享降采样层，最长边不超过640像素，按实际绘制变化合并更新、最多10次/秒；工作线程柔化，GPU纹理三角网格折射及细亮边。前景文字/图标随后绘制，不参与柔化。Android13+继续原AGSL路径。保留硬件加速、高开销主题授权和非低负载约束；设置显示“兼容模式可用”。窗口仍复用完整页面（含海报墙），不压暗外部。
- 灯带边缘5%优先，暗边向自己的内部扇区逐层扩展。播放颜色按固定幅值归一、三帧中值滤波和约450ms时间平滑；亮度仍由原亮度设置控制。黑屏保留稳定颜色；短促闪电不能留下持续振荡。取色暂时失败保色，缓冲不再反复切换固定色/视频色。明确暂停/退出继续沿用固定色/熄灯生命周期。
- 蓝牙静态画面也每1.5秒刷新，周期重新确认自定义静态效果；每15秒查询远端状态、6秒无响应关闭失效连接。异常后有限退避重连（每次故障最多10次，间隔1.5–30秒），连接成功续发上一组颜色。显式断开取消待重连；不会无限堆积待发送帧。固件/设备校验与原96单元四角校准保持。
- 视频层使用明确的原生尺寸：适应等比容纳、裁切等比覆盖、拉伸独立改变宽高。只调整视频内容框，不缩放字幕/OSD、不重建播放会话。裁切/拉伸时低频检查解码缓冲区，连续三次一致才识别片源自带黑边；裁切放大并裁去侧边，拉伸让有效图像变形铺满。暗场或孤立闪电不识别为黑边。
