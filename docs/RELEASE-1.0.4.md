# SunnyTV 1.0.4

本版汇总 1.0.0 后的界面、音轨、灯带与播放修订，版本号 1.0.4，构建 77。沿用现有签名和安装 ID，可从同签名旧版覆盖升级。

- 重绘 SunnyTV 矢量图标，设置改用三推杆，媒体库使用叠放卡片，播放控件更清晰。
- 玻璃弹窗取样完整页面，包括海报墙；内层磨砂聚焦、选项对齐，外侧保持亮度，圆角上限 24dp，底色增加至 21%。
- 剧集与季详情增加默认音频图标，按选择的语言优先播放；电影、单集仍直接选择音轨，手动选择优先。
- Android 11–12L 增加真实页面背景的玻璃兼容模式，Android 13 以上沿用原生着色器。仍需硬件加速、开启「允许高开销主题」并关闭低负载模式。
- 灯带优先取屏幕边缘，暗边向内部扇区扩展；固定亮度、平滑换色、过滤短促闪电，黑屏保留稳定颜色。增加连接健康检查、有限退避重连与颜色恢复。
- 裁切保持比例放大并裁去多余画面，拉伸独立改变宽高；连续检测片源自带黑边，字幕和操作栏保持原尺寸。
- SunnyTV 官网接入 SunnyUI 2.1 的实时网页玻璃，保留默认白色、黑白主题及原生截图，完整模拟器继续暂停。

本地 release 与测试包编译、203 项单测、172 项核心契约通过；完整 lint 零错误（debug 45、release 48 项警告）。最终签名 APK 在 API30 TV 和 API34 模拟器各通过 13 项定向回归，涵盖玻璃、灯带、真实视频裁切/拉伸与默认音频。实体电视的流畅度、真实闪电片段和长时间蓝牙恢复仍待用户测试；自动黑边识别也可能保留非常暗或非标准片源的黑边。详细边界见 [本地验证记录](RELEASE-1.0.4-LOCAL.md)。
