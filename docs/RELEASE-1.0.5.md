# SunnyTV 1.0.5

本版根据Android11雷鸟电视现场日志修订灯带、画面裁切和电视玻璃兼容效果。手机端液态玻璃与Android13+渲染保持原样。

- 灯带增加统一RGB负载限制，降低大面积白色导致的闪烁风险；保持色相及原亮度设置。限制以本次灯带整条白色24%不闪的反馈为保守参考，实际输出可能低于所选亮度。
- 颜色更新不再重复重选静态灯效。4K取色改为读取完整解码缓冲，再按屏幕可见区域取样，修正视图尺寸与解码尺寸不同导致的取样范围错误。
- 灯带与黑边识别避免同时读取视频；取样耗时较高时自动降频。识别稳定黑边后停止持续扫描，减少电视播放负担。
- 电视裁切改由解码器执行等比中心裁切，与拉伸模式分开；编码黑边仍通过完整画面检测。手机的画面缩放路径不变。
- Android11–12电视玻璃使用实时背景图层及轻量边缘折射，避免背景位图在滚动中冻结及频繁读回。兼容效果采用轻量近似，手机原玻璃实现未改。

## 验证与待复测

本地212项单元测试通过、零失败/跳过，Android测试代码和release编译通过，debug/release lint零错误（48/45项警告）。最终发行使用既有签名与完整CI检查，结果以本版GitHub Actions为准。

本轮已读取实体电视1.0.4的版本、日志和图层信息；新包未安装到用户电视，用户稍后自行复测。实体裁切/拉伸、灯带长时稳定和杜比视界白色偏蓝尚未验收。杜比视界硬件视频层在普通截图中不可见，不保证该类视频已能可靠取色。负载限制不是电源/线材故障的硬件修复。
