# SunnyTV 1.0.6

- 灯带取色改用32×18小色网格，四边平均后均匀着色并平滑过渡，减少颜色处理与读回数据量。
- 按实际耗时自动降低刷新频率，控制读回时间预算；等待时不持续轮询。若电视单次读回超过250ms，暂停当前视频的同步并保持灯色，优先保证播放。重新开关画面同步可重试，原配置保留。
- 黑边检测遇到高开销视频层时停止扫描、保留当前比例，减少对播放的影响。
- 液态玻璃聚焦文字、图标和已有描边跟随系统/主题强调色；手机玻璃材质和折射实现保持原样。

1.0.4/1.0.5实机对照已确认慢视频层读回会伴随丢帧，关闭同步后该视频稳定输出约25fps。本版的小网格无法保证消除厂商驱动等待，首次探测仍可能停顿一次；高开销视频暂停同步属于保护行为。新版本实体长时表现、杜比视界取色仍待复测。
