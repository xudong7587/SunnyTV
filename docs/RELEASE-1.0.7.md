# SunnyTV 1.0.7

- 海报墙增加明显的主题色聚焦外框，玻璃按钮使用同一重点色外框，方便遥控器辨认当前焦点。
- 修整 Android 11–12L 电视玻璃按钮的边缘拼接与高光描边，减少细黑线和粗糙边缘。
- 播放器玻璃按钮以重点色图标和圆形外框显示聚焦，去掉额外的矩形灰色反馈。
- 修复“跳过片头/片尾”向下离开后无法按回：底部按钮、进度条和跳过提示可以往返，选择跳过或“暂不”后焦点返回进度条。
- 灯带按实际取色耗时选择详细或轻量网格；慢但成功的取色继续低频更新四边颜色，不再一次超过250ms就停住当前影片同步。达到2秒的严重阻塞仍会暂停保护，重新开关同步或开始新播放可重试。
- 提高鲜艳模式的灯色饱和度；低频采样即时显示当前颜色，减少等待多帧造成的延迟。

慢视频层的低频同步可能落后画面数秒，单次 GPU 读回也可能影响流畅度；实际电视玻璃边缘、墙面灯色和长时播放仍需安装后复测。本轮不连接或操作用户电视。

版本号 **1.0.7**、versionCode **80**，沿用既有安装 ID 与发行签名，不覆盖历史版本或附件。正式 APK 经过 CI、签名与包身份检查后发布，并以相同字节投放电视安装目录。
