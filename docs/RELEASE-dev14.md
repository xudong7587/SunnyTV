# SunnyTV 0.1.0-dev14

开发测试版，基于 dev13 增量修复，不更换应用包名或重写播放器。

## 本版更新

- 首页增加显式的纵向焦点路由：媒体库入口、下一集、各库标题和媒体海报之间先显示目标区域，再移交焦点；连续向下可进入尚未显示的媒体库。
- 从媒体库卡片向下时保留选中的库；返回时恢复对应卡片，不再默认跳回前两个入口。空库、下一集开关和跨来源同名库有独立处理。
- 浅色聚焦改为低透明度暖灰双层阴影、轻微上浮和缩放，减少动画时保持静态反馈；深色保留清晰焦点框，不使用彩色外发光。
- 横排首尾与自动滚动保留安全空间；焦点线画在卡片边界内，避免最左/最右卡片与描边被裁切。
- 关于页仅保留 SunnyTV 的名称、版本和功能说明。源码许可证和必要的第三方声明不变。
- 延续 dev13 播放控制按钮与布局重置。纵向 4K MP4 播放修复保持不变；此前真实设备验证结论沿用 dev13 记录，本轮未重新执行电视播放测试。

## 验证范围

新版本必须通过单元测试、lint、Android APK 编译及定向模拟器回归后才发布。
本次没有连接用户的电视、Emby、CloudDrive2 或网盘账户，不宣称进行了实机性能或全片源验证。
