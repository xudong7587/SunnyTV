# SunnyTV v0.1.0-dev15

## 本版修复

- 浅色主题改为独立绘制的柔和投影：暖灰接触层与扩散层，不再依赖系统 elevation 阴影的透明度；保留阴影开关和减少动画设置。
- 修复首页轮播大方块与细条海报上下错位：细条列表不再继承普通媒体横排的额外留白。普通媒体库横排仍保留边缘保护。
- 轮播/手风琴海报保持同高，不再对单张焦点海报做额外缩放或上浮；媒体库卡片的轻微悬浮反馈保留。
- 发布签名固定为 dev14：缺少密钥或与 dev14 证书不一致时阻止发布。

## 验证与范围

本工作流要求单元测试、lint、APK 编译、dev14 覆盖升级标记检查、5 项既有焦点回归与 4 项阴影/轮播仪器测试通过后才发布。
阴影测试采样卡片外侧的真实截图像素，不能只检查焦点边框或源码参数；轮播测试检查聚焦前后及切换中的顶部、底部和高度。

不改 MediaIndex、Emby/CD2 来源适配、播放器解码或播放进度逻辑。保留之前的 MP4 兼容修复。本轮未连接用户电视，没有将模拟器像素/交互测试当作实机性能验收。
