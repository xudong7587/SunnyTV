按实机反馈修的一批手感问题：详情页焦点、排序窗口、搜索布局、画面裁切与几个图标。

- **详情页焦点**：进入媒体详情默认停在「继续播放 / 播放」上，不再落在顶部导航；按上回到顶部导航、
  再按下回到该按钮。剧集把「继续播放」排在「从头播放」之前。
- **排序**：排序窗口改成一行三个的固定网格，十二个排序键同屏，不用翻页；
  选过靠下的排序键后重新打开，焦点仍停在该键上。排序按钮左侧改为一对等高的上下箭头表示方向。
  「比特率」与「大小」改在设备端排序：实测 Emby 的 item 接口会忽略这两个排序键（名称等键正常），
  现在按文件的实际码率 / 体积排，一次覆盖 200 条。
- **搜索页**：字母数字键盘移到搜索栏上方并整体居中，退格与清除放在字母与数字之间。
- **视图按钮**：单击即在海报 / 背景 / 横幅之间循环，不再进入子菜单。
- **画面裁切**：裁切只按屏幕比例挤掉多余黑边（18:9 裁两侧、16:10 裁上下），
  修掉此前额外放大 12% 造成的过度裁切。
- **图标**：播放器快进 / 快退改为双三角并去掉秒数角标；睡眠图标重绘为新月。
- **STRM 兜底**：直连打不开时改用 Emby 服务端读取一次；HTTP 409 的提示改为指向失效直链或令牌。
