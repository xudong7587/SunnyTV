# SunnyTV v0.1.0-dev29

本版修复 dev27 对抗性审查确认的五项问题，不包含本地 Carlink 车载候选开发。

- **账号隔离**：拼音搜索仅汇总当前来源，切换来源会取消旧搜索并清理搜索结果；同一缓存键的内容更新能立即反映在页面中。
- **发行安全**：公开包改用明确关闭调试的 release 变体。安装 ID 仍为 `io.github.xudong7587.sunnytv.debug`，沿用仓库既有签名。包名中的 `.debug` 是历史安装身份，不代表本版开启调试。
- **WebDAV 解析**：改为流式读取 XML，在解析过程中限制元素数、深度、字段长度和条目数，保留 UTF-8、DTD/实体、来源与路径校验。
- **请求期限**：API、图片和 STRM 文本的单次请求增加 30 秒总期限，包含跳转和响应体读取。视频流保持独立的连接/读取预算，不设置 30 秒播放时长限制。
- **全库排序**：大小、比特率排序先读取完整媒体列表再排序，修复超过 200 条后的排序错误。一次排序最多 10000 项、累计 8 Mi 字符响应、90 秒；超限、分页重复、数量变化或结果不完整会明确提示重试或进入更小的文件夹，不显示伪全库排序。

升级沿用原包名和现有证书，无需卸载旧版。未替换任何既有标签或发布资产；dev28 编号已用于本地车载候选，本次公开版本顺延为 dev29。

验证记录见 [SEC-01](iterations/SEC-01-dev29.md)。原有 TV 仪器化已知问题仍按 [KNOWN-ISSUES](KNOWN-ISSUES.md) 跟踪，本轮没有将定向回归结果写成全部电视场景验收；真实 Emby/CD2 服务、实体设备和 Apple 平台未重新验证。
