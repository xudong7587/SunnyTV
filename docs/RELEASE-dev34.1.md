# SunnyTV 0.1.0-dev34.1

基于 dev32，独立修复分支，不合并电脑上的 dev33。

- 不支持的音轨不再隐藏，添加 Emby 音频兼容入口；当全部音轨不受设备支持或音频解码失败时自动尝试一次，界面显示状态。兼容模式请求原视频复制、AAC 双声道，需要服务端音频转码权限。
- 详情页音轨选择按实际音频序号应用；Emby 文本字幕可由服务端提取，并用稳定编号选择。
- 排除过早的片尾标记及普通章节名称误匹配。
- 详情页和播放器支持通过 Emby 已配置插件搜索、下载字幕并选用。连续剧记住提供者与语言；后续播放逐集搜索，仅自动下载插件返回的精确哈希匹配，不保证每集都有结果。

验证：CI 必须通过单元测试、debug/release lint、release 编译、包身份和现有密钥签名检查后才发布。电视 DTS-HD/EAC3、NAS HLS 服务与字幕插件端到端行为尚待实机验证，不宣称已验证。

使用：播放器 → 音轨 → 无声？使用 Emby 音频兼容模式；字幕 → 查找并下载字幕。

补丁：字幕搜索弹窗独立于主界面 AppModel，在播放器可正常使用；音频兼容状态直接显示在控制栏。
