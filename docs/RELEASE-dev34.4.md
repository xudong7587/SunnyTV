# SunnyTV dev34.4

基于 main 的 dev34.3 修正。播放页右上角新增音频输出，默认原始声道；可选择双声道或 5.1。仅在本机合并超过所选上限的 PCM 声道，保留中置人声，不伪造环绕声，不请求服务器转码。切换保留播放位置、暂停状态、音轨、字幕和倍速。选择在当前播放会话及旋转后保留，新播放默认原始声道。

字幕下载仅对该请求延长读取预算至 90 秒、总时限 120 秒；成功空响应或缺少 NewIndex 时，比较下载前后的轨道找到新字幕，等待最多 20 秒媒体信息更新。错误提示显示安全的实际 HTTP 状态或超时原因，不再一律归因于权限。不会自动重试下载 POST。服务器真实字幕下载仍需用户验证，没有服务器日志不能保证所有插件失败已修复。

保留 dev34.3 的本机解码、字幕和片尾修复，dev33 不改动。新增 Android 测试覆盖六/七/八声道中置混入左右声道、7.1 到 5.1 保留中置及双声道不扩展；HTTP 测试覆盖 204 响应后发现新字幕和 403 状态保留。

沿用现有签名，versionCode 38。真实海信电视的人声和服务器字幕下载需实机确认。云环境无 WebDAV 升级目录挂载，未同步。许可证和音频库来源及重链接材料同 dev34.3。
