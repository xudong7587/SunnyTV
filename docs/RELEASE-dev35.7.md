# SunnyTV dev35.7

新增 MediaIndex 配套转码服务的画质选择：原片、4K、2K、1080P、720P 与对应码率档位。原片保持既有直放链路，指定画质通过服务端临时 HLS 播放，不新增媒体库条目。

清晰度圆形按钮跟随所选档位显示文字，修复文字上叠加十字图标；转码失败提示 HTTP 状态，分片 504 提供有限重试。增加原片带宽与缓存估算提示，修复详情页演员区域向下导航，并增加官方 GitHub 发行页下载入口，校验哈希、包名、较新版本和签名后交由系统安装。

沿用既有安装 ID 和签名，保留 main 已合并的本机音频解码功能。dev35.7 是本轮改动首次 GitHub 发行，包含本地 dev35–dev35.6 的增量。

本地 dev35.6 编译及单元测试通过；dev35.7 的远程构建、lint、签名及定向 Android 验证以本次工作流结果为准。MediaIndex worker rc.4 已在 NAS 验证同一续播位置的 1080P/4Mbps、4K/20Mbps 分片均返回 200，并保留烧录字幕；电视持续播放、焦点和 GitHub 内部安装仍需实机验收。4K HDR 色调映射性能取决于 NAS，不能保证实时转码。
