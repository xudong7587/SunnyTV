# 0.2.5 字幕与缓冲增量修复

基线：`v0.2.5` / `f33a35b52ea907143ef59320b8b092fbf93998a8`。

- 原片内嵌字幕切到云端时保留实际轨道身份，通过只开放文本轨道的原片媒体源与云端 HLS 合并，不再强制改成 Emby 字幕提取地址。原片读取使用原有来源鉴权作用域，云端 CDN 不接收 Emby 凭据。需要原片仍可访问；容器提取可能增加原片读取量。Media3 本身不支持的字幕格式仍不会被伪装成可播放。
- 播放器和字幕菜单增加字幕微调入口，左侧回退字幕进度、右侧前进字幕进度，步长为 10 / 3 / 0.5 秒，支持累计偏移和归零（范围 ±300 秒）。实际偏移同时作用于字幕样本与字幕 seek，不移动音视频时间轴。多次操作合并后在当前视频位置重新准备播放器，以恢复已经丢弃的历史字幕；可能短暂重新缓冲。保持暂停/播放状态、倍速和所选清晰度，切换媒体归零。
- 微调浮层位于上方，底部控制栏隐藏；按浮层实测高度给完整视频和字幕预留区域，临时使用适应画面模式，关闭恢复原模式。按钮支持触摸和遥控器，手机窄屏分为两行。
- 预读预算改为 Java 最大堆的 1/3、上限 256 MiB，保留按字节停止读取的约束与原有 30–120 秒时间目标。79.13 Mbps 时，256/512 MiB 堆的理论容量分别约 9/18 秒，并非保证实测缓冲秒数；小内存设备仍保留堆空间。

回归涵盖内嵌/外挂切档、无提取接口、关闭字幕、PCE、六种步长、暂停位置不变、切档与拖动后偏移、归零、界面预留区、轨道身份与内存预算。新增独立 PR 工作流执行 Android 定向测试，不发布正式版。

本地环境仅有 JRE，缺少 javac、kotlinc、Gradle 与 Android SDK；`scripts/test-core.sh` 因 kotlinc 缺失未执行成功。网络代理不可用，不能下载工具链。Android 编译、单测和模拟器结果以本次 PR 的 CI 为准；实体电视、真实媒体与缓存体验尚未验收。未生成或替换正式 0.2.5 安装包。
