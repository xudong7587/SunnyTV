## TV与性能

检查启动、空首页、库网格、长标题、排序分页、详情/季集、输入法、弹窗、OSD、后台/休眠恢复。每页用方向键+确认+返回完成，不依赖鼠标。

媒体样本分别使用H.264 MP4、HEVC MKV、多音轨、内封和外置文本字幕、MP4元数据在尾部、MediaIndex真实STRM；HDR/DV/DTS/TrueHD独立建矩阵，不混用普通1080p测试结论。

性能分别记录焦点响应p50/p95、启动可交互时间、超时帧、峰值内存、首帧各阶段、seek恢复、30分钟资源增长；保持相同设备/网络/样本及release-like构建对照。现有指标没有端到端范围，不得宣传“1秒起播”。
