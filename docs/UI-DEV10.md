# dev10：TV 焦点、协调动效与字体

## 本轮改动

- 首页从顶部导航按下进入播放按钮，保持整幅推荐区的位置；向右进入轮播并切换海报，再按下才滚动到“我的媒体库”。媒体库行向上返回推荐区。
- TV 纵向容器在左右键导航时保持位置，横向列表使用独立的最小可见滚动规则，避免横向焦点引起纵向重新居中。
- 最新入库等 TV 宽窄卡片使用固定高度视口。相邻卡片在同一弹簧进度中互补宽度，其他卡片的位置保持稳定；到右端后固定焦点槽位并切换内容。末尾“查看全部”只平移整行，保留最后一张宽卡，反向操作按对应规则恢复。
- 页面进入/返回、主题底色、背景图、片名 Logo 和按钮状态增加过渡；退出页面的按钮立即停止接收焦点，支持过渡未结束时再次导航。
- 设置新增 0.5x、0.75x、1x、1.5x、2x 和关闭动画。0.5x 为半速、持续时间更长；关闭动画也停止首页自动轮播。既有“减少动画”配置仍按关闭处理。
- 剧集与季详情在收藏左侧分别提供“从头播放”和“继续播放”。从头按季号、集号选择最早单集；继续优先最近有未完成进度的一集，再选已看单集之后的未看集，无记录时从最早单集开始。季页面仅查询当前季，不批量修改观看状态。
- TV 首页隐藏分行加载失败提示文字，保留来源整体失败时的重试入口。
- 聚焦/选中按钮采用重点色深底、浅色文字，移除外侧重点色边框，使用轻渐变与阴影；取消焦点缩放造成的位置变化。
- 设置新增五档独立字号（0.85、0.925、1、1.125、1.25）与 TTF / OTF / TTC 字体导入。字体从系统文件选择器复制到应用私有目录，验证成功后保存；提供系统字体恢复入口，不分发外部字体文件。
- 实际执行 TV 输入框回归时补齐输入框遥控器向下的显式确认路径，保留 IME 逐项跳转及保存按钮。

## 动效依据

参考 [Apple HIG Motion](https://developer.apple.com/design/human-interface-guidelines/motion) 和 [WWDC23 Animate with springs](https://developer.apple.com/videos/play/wwdc2023/10158/) 的连续性、可打断和弹簧响应原则，并检索了 [GitHub SwiftUI spring 示例](https://github.com/GetStream/swiftui-spring-animations)。示例不属于 Apple 官方标准，本项目未复制其代码或引入 SwiftUI 库。

当前 Compose 实现由统一 MotionTokens 控制：无反弹临界阻尼弹簧，基础 response 约 0.4 秒（单位质量刚度约 246.74）；速度按刚度平方缩放。淡入淡出基准 240–400 毫秒。这些是本项目的具体选择，不宣称 Apple 为所有界面规定了统一时长。电视遥控器动画遵循本轮用户明确要求，保留完全关闭选项。

## 验证与限制

- `assembleDebug testDebugUnitTest lintDebug assembleDebugAndroidTest` 全部成功。
- 36 个 JUnit 方法通过，其中包含 114 项核心契约检查；新增续播选择、服务端观看日期解析与动效/卡片几何策略验证。
- Android TV 模拟器实际执行 23 项仪器测试并通过：原有 13 项交互、8 项动效/导航/剧集按钮、2 项字体导入与持久化。页面退出焦点检查修正语义断言后单独复跑通过，其余 22 项在完整运行中通过。
- 几何测试覆盖动画中间帧的无关卡片位置、纵向锁定、屏幕边缘切换、末尾查看全部、快速反向操作与关闭动画。已检查模拟器推荐区和媒体库页面截图，使用虚构条目，无真实来源凭据。
- lint 为 0 错误、27 警告，未关闭检查。警告包括既有依赖版本/Manifest 建议及 Compose Modifier 参数排序提示。
- 未把模拟器结果当作实体电视流畅度或 4K 高刷验收；真实海报解码、电视文件选择器、厂商输入法及真实连续播放仍需设备验证。本轮没有覆盖安装用户手机。
- 字体上限 64 MB；没有系统文件选择器的电视会显示说明。导入字体能否改善显示取决于字体字形、设备渲染与实际观看距离。
