# dev11：焦点可见性、首页滚动与播放器控件

## 改动

- 深色聚焦使用重点色浅色描边，浅色使用重点色深色描边；边框在图片内容上方绘制。首页轮播正方形与细条保持无描边。
- 阴影改成浅灰、等尺寸、右下 2dp 偏移，不再模糊扩散；深色仅按钮启用。设置提供持久化阴影开关。
- 轮播媒体库选择与上方开关统一为 13dp 间距。首页两个续播胶囊收窄，右侧增加向下浏览媒体库提示。
- 焦点填色动画在绘制阶段读取进度，宽窄卡片在测量阶段读取宽度、图层阶段读取透明度，减少慢速动画的逐帧内容重组。使用 Compose 每帧插值，不引入视频插帧。
- 首页推荐区与首行媒体库放进同一预先组合的区域，向下使用 420ms 基准、随速度设置缩放的有界滚动，避免滚动中才首次构建首行。
- 最新入库未聚焦时统一窄卡。离开该行先收起当前卡，再平移回初始序列；上下进入时聚焦并展开最左卡。选中标题旁入口时，将整行及底部 14dp 留白一起带入视口。
- 播放器采用透明圆形图标按钮、聚焦上方文字提示、轨道选项行，保留播放/暂停、前后跳转、音轨、字幕、画面比例和退出操作。参考 [Moonfin PlayerControls](https://github.com/Moonfin-Client/Smart-TV/blob/main/packages/app/src/views/Player/PlayerControls.js) 的视觉组织，使用原创 Compose 实现，未复制上游代码。
- 错误提示补充阶段、错误码和安全异常类型，并保存在设备诊断页；不保存完整媒体地址、异常原始消息或鉴权头。
