# dev12：焦点、首页遥控路径与 MP4 兼容

## 本轮目标

1. 浅色主题使用柔和、克制的悬浮阴影突出 D-pad 焦点；深色主题不使用阴影，以更粗的重点色浅色描边和扁平填色突出焦点。
2. 首页删去冗余的详情/暂停轮播按钮，明确“播放 → 两个快速续播 → 媒体库”的纵向路径；右侧轮播向左完整循环一轮后，再按左回到播放按钮。
3. 处理实机诊断“错误码 2000 · video/mp4 · UnexpectedLoaderException → IndexOutOfBoundsException”。

## 实现

- FocusTile 继续作为全局聚焦入口，因此按钮、媒体卡、媒体库、设置项统一获得新焦点效果。
- 浅色阴影改用 Compose elevation shadow，并在普通横向媒体行、首页媒体库和 TV Accordion 预留 12–14dp 安全边距，避免阴影被 LazyRow/固定视口裁切。
- 深色聚焦描边由 2dp 调整为 3.5dp；焦点底板不再使用上下渐变，降低视觉和合成复杂度。
- 首页不再由最外层 hero preview handler 抢占所有上下方向键。播放按钮向下先进入快速续播；快速续播再次向下才滚动至媒体库。
- 轮播卡在向左移动满一整个候选数量后保持焦点，下一次向左才回到播放按钮，防止刚进入轮播就意外退出。
- Media3 五个模块统一从 1.6.1 升到 1.10.1。AndroidX 官方在 1.9.0/1.10.1 已修复多个 Mp4Extractor ArrayIndexOutOfBounds 问题。
- 对仍匹配同一异常签名的 MP4，仅自动重试一次，并为 Mp4Extractor 设置 FLAG_WORKAROUND_IGNORE_EDIT_LISTS。其他格式、其他错误不进入此回退。

## 边界

- 没有开启 Emby 自动转码；优先修复本地 MP4 解析兼容性。
- 不记录 URL、Token、Cookie、文件路径或原始异常消息。
- 真实纵向 4K 文件无法进入仓库测试，本轮只能通过单元/模拟器/构建检查和用户电视复测共同确认。
