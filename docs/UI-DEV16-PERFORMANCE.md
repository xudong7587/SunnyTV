# dev16 性能与焦点优化候选

基线：dev16 `e19b1e349f1c23101e49f5fc82545bd23a61cc31`；从 main `d9dbbd4b5047dd79ec714c206f17b1be4045ae1f` 建分支（这一步差异仅为状态文档）。保留 applicationId、versionCode 16、versionName 0.1.0-dev16，不覆盖原 dev16 标签或发布资产。

## 实施范围

- 浅色主题：主题色 2dp 聚焦描边与阴影共存，焦点不缩放、不上浮。
- 共用可见性策略：完整可见的目的行不滚动；网格越界按行高加间距平滑移动；超高行以首端可见为降级规则，避免来回纠正；连续方向键不堆积任务。
- 单库工具栏：只组合一份真实工具栏，网格索引 1 是非交互占位；滚动时标题、排序、字幕、呈现、文件夹视图停靠顶部；返回上方推荐有平移动画。
- 首页删除独立播放入口，保留两项继续播放，追加向下查看更多媒体；修正被删除按钮遗留的 FocusRequester 路径。
- 首页跨行优先媒体，左侧三分之二上下不经过右侧排序；排序常显当前文字与双向箭头，取消独立进入按钮，末尾查看全部仍能进入库。
- 手机窄屏首张与其余卡片均为窄海报，消除额外左缩进；电视行高从 213dp 收至 183dp，移除额外尾部空白。
- 首页、单库和详情显式滚动共用动画速度；详情与网格长按采用单任务保护。
- 图片磁盘缓存可选 128 / 256 / 512 / 1024 MiB，默认 512 MiB。下次进程启动生效，不将磁盘额度当作运行内存额度；内存仍按堆大小约束、低内存设备上限 32 MiB。
- 显示专用首屏快照：按来源、端点、用户隔离；JSON 白名单，不缓存凭据、媒体路径、播放地址或外部链接；单文件 512 KiB、目录 8 MiB、有效期 7 天；失效/损坏视作未命中；清理后拒绝先前排队的写入；网络后台重新验证。
- 低负载模式：海报请求上限 1280 像素、减少阴影轮廓绘制、取消图片加载器内部叠加淡入，保留滚动动画，不降低视频分辨率；自动模式依据低内存设备标记，网络并发预算重启生效。
- 设置拆分为来源、主题、外观、首页、字体、性能、播放、设备与诊断、关于；迁移旧分类，分类导航本身可以滚动。
