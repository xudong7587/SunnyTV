# SunnyTV dev20 UI / Focus / Player 修复说明

## 媒体库

- Hero → 工具栏：先移动焦点，不触发显式纵向滚动；进入工具栏后额外保持两个渲染帧的 bring-into-view 抑制窗口。
- 工具栏：标题保持文字；排序、字幕、呈现、文件夹/剧集布局均为 48dp 圆形闲置按钮，聚焦时才展开文字。
- 排序：日期、名称、评分、年份、播放历史、时长、码率、大小、随机分别使用不同图标；非随机排序叠加升/降序方向小标。
- 海报墙：按 Emby `total` 创建 LazyGrid 虚拟槽位。未获取的数据是可聚焦空块；可视空块请求下一页，返回后原槽位原地替换为媒体卡。
- 删除显式“加载更多媒体”焦点项，避免分页后焦点回到顶部工具栏。

## 首页 Hero → 我的媒体库

- 桌面/TV Hero 预留约 104dp 下一块内容，使“我的媒体库”在按 Down 前已经进入 Compose 预布局范围。
- 首行媒体库图片使用与实际 LibraryCard 相同的 420px 目标策略预取，减少按 Down 同一帧发生图片请求/解码。
- 过渡只执行一次 Hero 边界滚动，焦点在滚动完成后交给首个媒体库卡片，并继续短暂抑制系统二次 bring-into-view。
- 轮播海报 Down 直接进入媒体库；继续播放只保留同级左右导航。
- 左侧继续播放按钮底边与右侧轮播海报底边对齐。

## 播放器

- OSD 自动隐藏为真正的空闲计时：可见状态下任意 D-pad/按键操作，以及触摸/空鼠交互都会刷新计时。
- 播放、暂停、上一集、下一集、快进/快退、章节、字幕、音轨、演职员、画面、信息、退出等使用统一居中的实心/半实心几何图标。
- 倍速改为居中的实心速度徽标，睡眠使用居中实心月牙，避免旧版线条图标在焦点圆中上下偏移。

## 验证状态

- `scripts/test-core.sh`：114 / 114 通过。
- `scripts/check-project.py`：XML、Python、资源约束通过；源码包原有 3 个 shell 辅助脚本仍被检查器判为 bash 语法失败，本版未改这些无关脚本。
