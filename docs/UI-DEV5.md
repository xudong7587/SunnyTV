# dev5：手机手势与界面缩放（2026-09-17）

在 dev4 上增量处理四项补充反馈。

- 轮播与详情的文字标题明确使用 1.2 倍行距；Logo 加载占位高度至少容纳两行，播放器标题同步补充行距。
- 播放页左/中/右三分区：左侧上下滑调当前窗口亮度，右侧上下滑调媒体音量，中间横滑预览进度并在松手时提交一次 seek。取消拖动不跳转；不能 seek 的媒体显示提示。横向滑过整个画面宽度对应 120 秒，目标限制在媒体时长内。
- 双击左/右三分之一后退/前进 30 秒，中间双击播放/暂停；单击切换控制栏。OSD 按钮与轨道面板位于手势层上方。亮度不写入系统全局设置；音量使用普通 MODIFY_AUDIO_SETTINGS 权限。
- 混合库（含 Emby 返回空 collectionType 的库）显示最右侧文件夹模式入口；电影库仍隐藏。去掉独立升降序按钮，排序按钮常显当前方法与方向，再选同一方法翻转方向。
- 设置 → 首页与外观增加五档 UI 大小：80%、90%、100%、110%、120%。点击即时应用并保存；播放器界面也读取同一档位。视频表面保持全屏，缩放不重建播放引擎。
