# dev6：TV 布局、焦点与 4K 预览（2026-09-17）

以 TV 横屏为主，手机竖屏使用紧凑布局。沿用 dev5 手势和五档缩放。

- 背景移出 safeDrawingPadding；具体媒体库与详情页隐藏顶部导航，并移除其顶部占位。导航文字仅聚焦时出现。
- 导航使用明确的内容焦点入口；首页从轮播区域按上键回顶并返回导航，导航获得焦点时恢复完整轮播。媒体库头部、详情操作行获得焦点时同步恢复顶部内容。
- 剧集/季轮播增加播放入口。显式点击后用只读 Episodes 查询选择续播中未看完的一集，否则第一未看集，再否则第一集；只向该单集提交播放协商，保留整季已看写入禁令。
- 详情使用 i 图标，设置使用齿轮。移除按钮阴影、重复玻璃层和详情下方外部元数据链接按钮；资源卡仅保留一层底色。
- 设置分类等宽。轮播内容与时间采用整行设置；删除首页展现方式入口。参与媒体库选项独立折叠，默认收起，焦点离开该区域自动收起。
- 浅色背景、面板从重点色派生；首页不再强制深色，四周遮罩和底部渐变与页面配色衔接。
- 首页最多一张方形主卡加六张细条，细条填满可用宽度，保留两侧相同外边距；不足七条时显示实际条数。
- 最新入库及季集横向行默认展开第一张，离开后恢复首张并滚回开头。标题有查看全部入口，尾部查看全部固定为海报宽度。
- 各媒体库展示方式按来源和库 ID 独立保存；排序按钮只显示箭头和方法，再选同一方法翻转方向。
- Episode 宽图优先采用自身 Primary，避免被继承的剧集背景覆盖。
- APK 图标改用浅色底。继续播放胶囊固定高 48dp，内部海报直径 32dp、左留白 8dp，与左端半圆同心。

## 4K 与开销

预览脚本改为独立虚拟显示器 3840×2160 / 640dpi，逻辑布局与原 1920×1080 / 320dpi 一致；不修改手机全局分辨率。
文字和线图标由 Compose 在目标像素密度下绘制，海报及 Logo 请求尺寸随密度增加，避免固定低分辨率图片在 4K 直接放大。
图片共享缓存限制为堆内存的 10% 与 64 MB 中较小值，多个来源不会重复扩大预算。
低内存设备将图片宽度上限设为 1920，并关闭全屏背景交叉淡入；其他设备上限 3840。卡片尺寸动画不逐帧改变图片请求尺寸。
这是开销控制措施，不是低端电视或 4K 帧率的实测结论。预览使用手机独立显示器，不是电视硬件模拟器。
