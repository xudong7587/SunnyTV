# dev7：选集排布、返回导航与开源发布

2026-09-17，按用户本轮四项反馈继续在 dev6 上开发。

- 首页最新入库标题改为“媒体库名 · 最新入库”；右箭头紧邻标题，聚焦后显示“进入媒体库”。缩小标题上下与连续入库行之间的空白。
- 剧集/季的库内工具栏提供三个独立排布按钮：横向海报（下方两行简介，超出省略）、竖向单集列表（右侧简介）、数字选集（紧凑网格）。同一父条目的选择独立保存，详情的单集区域也共用这些排布。
- 去掉媒体库头部因焦点更新反复回顶的逻辑。头部按下键先进入工具栏，继续进入下方内容；按上键可恢复完整顶部。
- 媒体库的播放/详情操作旁增加返回按钮，详情头部增加返回按钮。Compose 显式处理 Back/Escape，手机系统返回手势仍走标准 BackHandler。
- 隔离测试宿主使用默认设置与内存设置更新，不读取真实账号，也不写入用户偏好。
