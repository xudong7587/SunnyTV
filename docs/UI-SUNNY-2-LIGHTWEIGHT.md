## 性能边界

没有新增依赖、图片请求、图片解码、背景抓取、RenderEffect、RuntimeShader、持续动画或全屏离屏缓存。图形对象按尺寸/主题缓存，焦点只读绘制阶段的颜色动画值。旧的浅色聚焦多轮廓软阴影不再用于这两种材质。图片尺寸上限、共享缓存、低内存判断、播放层与网络契约未改。
