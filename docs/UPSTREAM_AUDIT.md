# 上游与参考审计

## 本次实际使用

- Android/Compose/Media3/OkHttp/Coil作为依赖使用，没有拷贝它们的仓库到工程。
- Moonfin官方仓库在前序方案中确认有源码及Android Media3模块；本轮没有移植任何Moonfin源文件，因此不要标注SunnyTV已继承其DV/直通等能力。
- 用户的MediaIndex仅通过已读取的STRM/播放接口契约适配，没有修改、复制其服务端实现。前序读取的playback API文件SHA为`9d02398154979f2a902d63f2e2211000fcb560c0`（文件内容SHA，不是整仓提交SHA）。运行镜像版本未核对。
- 视觉参考是用户提供的LumiPlayer截图。没有取得可信完整介绍视频帧；其他页面为原创延展。
