# SEC-01：审查修复的边界与兼容性

日期：2026-09-27；基线 `6eada70`。本次只处理已确认的五项审查问题。

账号搜索在汇总入口按条目的 sourceId 再过滤一次，并对搜索缓存键作精确匹配；页面直接观察状态值，避免仅记忆键列表。保留其它账号的正常浏览缓存，切换时取消旧搜索。

网络层对有界 API/图片/文本设置 30 秒 callTimeout，沿用原凭据作用域、TLS、跳转、Range、UA 与取消规则。播放器专用 client 不设置整流总时限；否则长视频会被固定时长中断。不改账号存储格式或播放授权模型。

DAV 使用系统 SAX 流式解析，不增加第三方依赖。限制 8 MiB 输入、200000 元素、32 层深度、16384 字符字段、10000 条 response。单个 XML 标记在进入 SAX 前限制为 32768 字符，避免巨大属性或命名空间表先于回调分配。只提取 DAV 命名空间的必要属性，合并成功的 propstat，忽略失败属性和越界 href。没有使用只在 DOM 构建后才生效的计数方案。

大小/码率没有已验证的服务端全库排序能力。为当前修复采用有界完整快照：按已有受支持的 SortName 分页收齐后在 Default dispatcher 排序，向页面交付完整结果。不采用“已加载数据排序”冒充全库；不引入持久索引数据库或 Provider 重构。代价是大库第一次排序需要多个请求；有明确容量/总耗时上限，超限失败而不是截断。未来持久索引可取代此实现。

公开 APK 使用非调试 release 变体，保留现有安装 ID 和 Secret。未显式指定既有密钥时只允许生成未签名 release；发布流水线要求 Secret 存在，校验最终 APK 签名、调试标志、身份和私有字体/密钥排除项。没有生成替代密钥，也没有改变既有 tag。

回退：保持签名及安装 ID，通过后续递增版本回退单项实现。不得通过恢复公开包调试、取消解析预算或移除测试来回退。未知服务的兼容性异常应添加脱敏 fixture 再调整边界。
