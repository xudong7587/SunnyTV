# SunnyTV 官网

线上：https://sunnytv.dunn.fun:666/ 。纯静态 HTML/CSS/JS，沿用 Sunny UI 外观变量与许可，发布到既有 myblog 的 `sites/sunnytv`。

2026-10-22 已更新 1.0.0 /73 的标语、正式版摘要、浏览与播放能力、液态玻璃/极光/雾面、SP658E 灯带、MediaIndex 图标/介绍/链接、开源说明及 FAQ。所有下载入口继续指向 GitHub `/releases/latest`。

用户要求先发布官网内容，因此本次保留既有 `assets/home.webp`、`grid.webp`、`light.webp` 界面示意图；这一轮 imagegen 海报、横版背景及含新海报的截图仍为草稿，未进入线上首页或部署资源。旧截图为 Android 原生页面与原创虚构媒体数据，不读取用户媒体库。

部署仅包含首页实际引用的10个静态文件，资产先行、首页最后替换；排除草稿图片、QA页面和测试工具。320/390/768/1366宽度无横向溢出，线上10文件HTTP200及SHA256一致。详见 `docs/WEBSITE-DEPLOYMENT.md`。
