Emby绿联影视中心CloudDrive2STRM
绿联影视中心怎么连接？ ＋
  1. 在绿联影视中心「设置 → 服务管理 → 媒体服务器」开启服务，设置专用媒体账号。
  2. 在 SunnyTV「设置 → 媒体来源」选择「添加绿联影视服务」，填写服务地址、端口与账号。
  3. 使用服务页面显示的地址与端口；远程访问填写有效的 HTTPS 入口。不同固件的菜单和兼容能力可能不同。

开始之前

SunnyTV 自带影视资源吗？＋

不内置影视内容。需要连接自己的媒体服务，并拥有相应访问权限。本站图片使用原创虚构影片资料。

图中的玻璃外观已经在下载包里了吗？＋

本轮一体玻璃截图来自调整后的原生开发版本。官网正式下载仍为 1.0.0 /73，本次没有替换既有 APK；液态玻璃需要 Android 13 以上及硬件加速。

怎样更新和反馈问题？＋

应用内优先使用 GitHub 更新，官网始终指向 最新正式版。问题可在 GitHub Issues 反馈。完整更新见 1.0.0 发行记录。
