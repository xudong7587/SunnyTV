浏览媒体库、查看电影与剧集、继续播放。绿联服务通过 Emby 兼容接口接入，提供独立的添加入口与配置说明，并支持在 SunnyTV 内对媒体列表排序。

绿联怎么连接？ ＋
  1. 打开绿联「影视中心 → 设置 → 服务管理 → 媒体服务器」。
  2. 开启服务，设置媒体库专用账号和密码。
  3. 在 SunnyTV「设置 → 媒体来源」选择「添加绿联影视服务」，填写 HTTPS 服务地址及专用账号。

使用媒体服务器显示的地址和端口；外网填写可访问的 HTTPS 入口。不同固件的设置位置可能略有差异。

兼容能力随服务版本而异；部分 Emby 管理操作在绿联服务中不可用。

开始之前

SunnyTV 自带影视资源吗？

不内置影视内容。需要连接自己的 Emby、绿联影视中心或 CloudDrive2 WebDAV，并拥有相应访问权限。

支持手机和平板吗？

支持 Android 电视、手机和平板。电视使用遥控器焦点导航，手机和平板支持触摸、播放手势与方向锁定。

绿联连接需要申请开发者权限吗？

SunnyTV 当前使用绿联媒体服务器的 Emby 兼容接口。使用时需在支持的影视中心版本中开启媒体服务器，并创建专用账号；NAS 应用开发用的设备签名与此不同。

如何更新或反馈问题？

官网的下载入口始终指向 GitHub 最新正式版。应用支持 GitHub 更新与自行配置的 WebDAV 更新；问题可提交到 GitHub Issues。
